# Campus Grid — React

A React (Vite) build of Evergreen Campus Hub: the marketing landing page plus the core **Student Life Score (SLS)** product flow — identity intake → 60-question assessment → scored results with tiers, badges, and recommendations.

## App flow

- **`/`** — Landing page (hero, stats, pillars, features, testimonials, FAQ), ported from the original static site.
- **`/identity`** — Student Identity Page: collects basic info, campus involvement, interests, an identity statement, and the community pledge.
- **`/assessment`** — The SLS assessment: 6 sections × 10 questions (60 total), one section at a time with a progress bar, ending with the "missed opportunities" question.
- **`/results`** — Computed Student Life Score (0–600 → 0–100%), result tier (Disconnected Student → Campus Legend) with badge and color, a per-section score breakdown, personalized recommendations, and the missed-opportunity insight.

State (identity, in-progress answers, results) lives in `src/context/AppContext.jsx` and is persisted to `localStorage`, so a refresh mid-assessment won't lose progress. "Retake Assessment" clears answers and sends you back into the flow with the same identity.

## Scoring

Every question has 5 answer options worth **10 / 8 / 6 / 4 / 2** points. Section score = (points earned ÷ section max) × 100. Overall score = (total points ÷ 600) × 100, mapped to the 8 result tiers from the brand doc (Campus Legend, Campus Insider, Connected Leader, Opportunity Explorer, Active Participant, Emerging Explorer, Campus Observer, Disconnected Student). See `src/data/questions.js` and `src/data/results.js`.

## Getting started

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`). Click "Take Student Life Score" (or "Register") anywhere on the landing page to enter the flow.

To build for production:

```bash
npm run build
npm run preview
```
